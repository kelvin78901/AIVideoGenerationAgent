# 可点击原型

这里是原型的源文件，一个 `.dc.html` 是一个页面。它们是在 Claude 的设计画布里做的，依赖画布运行时（`support.js`，不在这里），**不能直接用浏览器打开运行**。要看效果，请 Kelvin 打开在线画布（私有链接，需要他分享）；要读结构和数据，直接读源文件。

## 怎么读一个 `.dc.html`

- `<x-dc> … </x-dc>` 之间是页面的 **布局和文案**：普通 HTML + 行内样式。
- `{{name}}` 是从脚本里取的值；`<sc-for list="{{items}}" as="item">` 是循环；`<sc-if value="{{flag}}">` 是条件；`onClick="{{fn}}"` 绑定事件。
- 页面底部 `<script type="text/x-dc">` 里的 `class Component` 是 **数据和交互**：`this.state` 是页面状态，`renderVals()` 返回模板要用的值和处理函数。示例数据（镜头、花费、质检分、模型列表）都写在这里。
- 页面之间用 `<a href="Xxx.dc.html">` 跳转。

正式实现时：布局、文案、交互流程照原型；视觉按 SPEC 16.4 重做（原型是线框级的中性风格）；数据换成后端接口。

## 共用交互清单（每个产物页都要有）

- [ ] RunBar：当前产物、版本、模型、本地 / API、时间、状态；改提示词 / 重跑 / 不满意换一个（下拉选模型）/ 历史 n
- [ ] 右侧 Inspector 三个标签：运行设置 / 提示词 / 历史
- [ ] 运行设置：运行位置（本地 / API / 混合，不可用的置灰并说明）、API 服务（前 6 个 + 更多供应商）、本地模型、自动兜底（开关、触发条件、兜底到）、单次花费上限
- [ ] 提示词：意图层（自己的话）、编译后预览、直接改编译层（改后标“已手动修改”，可恢复自动编译）、保存并重跑 / 只保存
- [ ] 历史：每个版本的模型、位置、时间、花费、备注；设为当前、采纳这一版
- [ ] 改已确认的上游 → 影响范围：只标记待更新 / 自动重跑（显示预计花费）/ 撤销
- [ ] 顶栏：成片规格标签（点了进规格页）、GPU 状态、本集花费 / 预算、中 / EN
- [ ] Toast 反馈每个操作的结果

## 示例数据

示例项目是《雨停之前》第 1 集《红伞》：人物林晚、周屿；2 场 9 个镜头（1-01 到 1-09），成片 34 秒；本集已花 $8.94，预计 $13.35，预算 $15；42 次调用 1 次失败。小说片段是为演示编的；API 单价按官方或公开价估算；花费、耗时、质检分、检测到的硬件等是示意，但各页和看板之间是对得上的。做 `tests/fixtures/demo/` 时以这些数字为准。
