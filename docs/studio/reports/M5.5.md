## 做了什么

M5.5 做了两件事。第一件是你看完第十七轮成片后定的根治方案：每个镜头带一份「镜头契约」，关键帧和视频都照它做，每一环出完都按它检查（只提示、不挡）。第二件是原来的图片来源与编辑：关键帧和参考图能上传、裁切、以它为底重画、局部修复、放大，素材能加多张参考图、换六视图的一张、手动新建，镜头有自己的参考图，剧有风格板。最后一步加了声音克隆。

**镜头契约和检查（第 2–9 步）**

- 契约（`shots/contract.py`，迁移 `0024` 的 `shot.contract_json`）：镜头类型和动作预算（insert 只许微动、performance / dialogue ≤ 2、action ≤ 4）、开始 / 结束时人和道具的状态、道具摆成什么样、每句台词是对白 / 画外 / 内心独白。分镜规划生成，缺的按规则补，分镜页能改；改了关键帧、视频待更新。
- 关键帧画开始状态和道具状态，尺寸写成和人比（「立着到人的胯部」）；视频改写按类型给动作预算，不许撤销重做，只演写到的；内心独白嘴闭着、不进 take。
- 道具带尺寸、材质、新旧；道具图实拍质感；有字的道具，字是道具的一部分（素材分析合并、道具图直接画字、OCR 核对）。示例剧的 `txt1` 并进了便利贴。比例参考（道具和人同框）做成了单独的组件 `scale`，第 9e 步起不再进关键帧（反而让伞变大）。
- 三道检查，都只提示：分镜（规则现算 + DeepSeek 补规则看不出的）、关键帧（Gemini Flash-Lite 看图 + OCR）、take（6 帧拼图 + 量出来的切点和定格）。第 9e-5 步起，关键帧和 take 检查没过会带着没过的几条自动重画，最多 2 次，还不过再提示（你 2026-11-11 同意）。
- 第十九、二十轮本机整集（第 9 步）：第十七轮的六条瑕疵都修好了；第十九轮重出时冒出的新问题（伞和人一样大、室内外融在一起、穿模）在第二十轮也没了。**你 2026-11-12 看第二十轮：和第十七轮差不多，保留，不回退。** 剩下的小问题见「遗留问题」。

**图片来源与编辑（第 10–18 步）**

- 上传关键帧：按成片画幅裁切（可拖动选位置），缩到交付尺寸，自动选中；分辨率不够只提示。确认镜头时锁定，视频首帧就是它。
- 素材：多参考图（每张标用途）、六视图换一张（上传或重画这一张）、新建素材（`manual`，重新分析不退场）。
- 镜头参考图（构图 / 姿势 / 光线 / 风格）和剧的风格板（在成片规格页管理）。关键帧取参考的顺序：素材主图 → 多参考图 → 镜头参考 → 风格板，取到模型的 `max_refs`，提示词里写清每张图参考什么。
- 三个新组件，结果都是新的候选（父版本是原图），照旧挑、锁、换回：以这张为底重画 `redraw`（本地 Klein，改动幅度 = denoise；API Nano Banana 2.1 / GPT Image 2）、局部修复 `inpaint`（前端涂遮罩；本地 Klein、API GPT Image 2）、图片超分 `iup`（只有本地 SeedVR2）。上传的图要出 API 版本，就用「以这张为底重画」选 API。
- 前端：首帧和素材候选的「换来源 ▾」菜单（上传裁切、重画、局部修复、放大）、素材页的多参考图和六视图悬停操作、新建素材、镜头参考图、风格板；亮 / 暗、2000 px 宽屏截图在 `reports/ui/`。
- 本机核对（第 18 步）：三个本地工作流在你的 5090 上体检、试跑通过；拿第二十轮 1-04 的真关键帧做了本地重画（风衣换色）、局部修复（便利贴写「等我」，遮罩外不变）、SeedVR2 放大，API 重画和局部修复各一张，共 $0.2245（`reports/m55-edits-smoke/README.md`）。

**声音克隆（第 19 步）**

- 音色来源「声音克隆」：上传 10 秒到 5 分钟的人声样本（WAV / MP3 / M4A，≤ 20 MB），勾「我确认已获得声音本人的授权」，再点「克隆 · 约 $1.40」（MiniMax）或「用本地出终版（免费）」（IndexTTS 拿样本当参考音频）。克隆没有试听，每次运行直接出终版，锚点就是你的样本。
- MiniMax 的接口和价格按官方文档核对过（2026-11-14）：$1.5 / 9.90 元，第一次用这个音色合成时才收；没用过的克隆音色 7 天后被删，所以克隆和出 5 个情绪变体放在同一次运行里。换样本会自动取消授权勾选；没样本或没勾授权时任务不会入队。
- **还没用真钱试过克隆**：MiniMax 要求账号先完成个人或企业认证。
