本地草稿：FLUX 3 Klein 明显好于 Qwen-Image-Edit。
- 1-01「米色风衣湿了半边」：Qwen 3/3 风衣上有黑白汁液，Klein 0/3（它先把提示词扩写成完整的场景描述再画）。

- 1-04 近景：Klein 是标准近景、林晚的脸和风衣对得上；Qwen 景别偏远，有一张背景里多了一个人、#0 画了两个林晚。

  1-07 两边都画出了 23:52（「后期贴字」没守住），Klein 的手机立在桌上、没有手。
- 速度：每个镜头 3 张 Klein 26–33 秒（含扩写）、Qwen 15–37 秒；显存峰值 Klein 23–25 GB、Qwen 31 GB。
API 终版（从 Qwen 草稿 #0 出）：Nano Banana 2.1 和 Pro 差不多，便宜一半多。
- 两家都照着草稿精修，草稿的毛病会留下来：1-01 两张终版都保留了风衣上的汁液。
