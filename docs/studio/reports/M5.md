## 做了什么

M5 把「分镜确认 → 每个镜头出几条视频候选（本地 H3 草稿）→ 挑一条 → 按按钮用 API 出 2K 终版 → 生成闸门」在后端做通了；工作流库从示例数据换成真实接口，导入社区工作流能体检、装节点包（先存快照）、试跑、登记成本地模型。

- Mock 下整条流程能走：示例第 1 集分镜已确认，1-01–1-03 已采纳终版，1-04 四条待挑（含一条本地超时兜底到 API 的、一条换 Seedance 的），其余镜头点「生成」就出。
- 生成页、工作流库全部接真实接口，对应的 MSW 删掉了。
- 你的 5090 上本地 H3 真出了 1-01、1-04、1-06、1-08（1-08 接 1-06 的真尾帧）；真导入了一个用 rgthree 节点的社区工作流，走完体检 → 快照 → 装 → 重启 → 试跑 → 我的工作流。
- 真实冒烟：H3 API、Regenerate-2K、Context-IR、DeepSeek 选工作流都跑通，共花 $1.16；Seedance 账号没开通，没跑成（你定先不管）。

**框架、工作流库（第 1–3 步）**

- 迁移 `0019`：表 `comfy_workflow`；`model_call` 加 `workflow_id / workflow_sha256 / comfy_env_hash / select_json`。`media/video.py`：探测、裁头（重新编码，按帧切）、取封面帧和尾帧。
- 工作流库是配置的一层：每个工作流登记成本地模型 `comfy/<slug>`，ModelPicker、路由、能力过滤都不用改就认得。仓库 `workflows/` 是推荐档，用户导入的放 `~/.drama-studio/workflows/`。未验证的只能手动选，不进「不满意换一个」、兜底、规则表。
- 导入：拖 JSON 或从 ComfyUI 自己的工作流列表选；UI 格式按 `/object_info` 转成 API 格式；自动猜绑定（首帧、提示词、种子、尺寸、视频输出…）。
- 体检：`/object_info` 找缺的节点类和模型文件，按 ComfyUI-Manager 的节点表归到节点包；装节点包先存快照；试跑是 GPU 队列任务，进度走 `job.updated`；装完自动体检全部工作流，之前正常、现在坏了的给「回滚到这次安装前的快照」。

**ComfyUI 适配器、H3 本地工作流（第 4 步）**

- 视频、音频进出 ComfyUI；WebSocket 进度（连不上回到轮询）；取回的视频校验时长和画幅。
- `workflows/h3-i2v/`（官方 I2V 模板，`tts` 和 `none` 镜头用，台词音频经 `MiniMaxH3AddGuide`）、`workflows/h3-r2v/`（官方 R2V 模板，原生同步的镜头用，收锁定音色样本，你选的 B）。第 14e 步按你定的改成 20 步、不开 Turbo。

**视频组件 `vid`（第 5 步）**

- 每个镜头一个视频产物，一条 take 一个版本；第一次出 2 条，「再出一条」1 条。
- 首帧：普通镜头用锁定的关键帧，连续镜头用上一镜**已采纳 take 的真尾帧**。声音按 `audio_mode`：`tts`（模式 A）喂拼好的台词音轨，`native`（模式 B）给锁定音色样本、H3 自己出声，`none` 不出声。
- 每条裁掉开头 0.3 秒，存封面帧和尾帧；关键帧、配音、参考图、镜头字段变了 → 待更新；改画幅的影响范围多一行视频重做。
- 生成闸门 `takes`：每个镜头都有采纳的 take 才能确认。

**API 适配器、出终版、兜底（第 6、7 步）**

- MiniMax H3（V2 接口）：生成、Context-IR（官方的提示词改写）、Regenerate-2K。有声音输入走参考生视频，否则图生视频。价格存人民币。
- Seedance 2.5（火山方舟）：只发首帧，按 token 记账，原生 1080p。
- 「用 API 出终版 · 约 $x」（你定的：按按钮，不在采纳时自动出）：本地草稿另存没裁头的原片和实际请求，Regenerate-2K 原样重发，终版的父版本是草稿。
- 本地 take 失败或超时：整条在兜底模型上按它的格式重做，版本记 `origin=fallback` 和原因，运行记录里记一笔。

**厂商站点和模型列表（第 7a 步，你插的）**

- 每个厂商能切国内站 / 国际站（Kimi、百炼、智谱、MiniMax 默认国内站），密钥按站点分开存。
- 写作模型按厂商自己的 `GET /models` 列表勾选；能填单价、改媒体模型 ID；**没单价的模型运行前先问**（补上硬规则 6 的漏洞）。Kimi 默认 K3.1 Pro。

**生成页（第 8、9 步）**

- 后端：生成规则（每镜候选数、单镜上限 $2）、运行记录、取消采纳、打分、单镜头预算上限、最小 `/metrics/summary`（表头花费）。

**工作流库前端、DramaStudio 节点包、按镜头选工作流（第 10–12 步）**

- 模型页工作流库接后端；ModelPicker 每个工作流带档位徽标，未验证的单独一组。
- 节点包 `integrations/comfyui-dramastudio`（13 个输入 / 输出节点）：用了它的工作流导入时自动生成绑定、不用猜；Setup 页可以装（先存快照）。
