种子 22 本来就不切；种子 191503631 只有官方写法那条没切。切过去的画面就是参考图本身（场景图、人物全身像），说明模型把单独一行的参考图当成了要切到的关键帧。

## 原因

MiniMax 官方的提示词写法（GitHub `MiniMax-AI/MiniMax-H3` 的 `h3-prompt-writing` 技能，`references/ref-en.txt` 和 `base-en.txt`）有三条，工作台的 `prompts/templates/vid/h3_r2v.j2`、`h3_i2v.j2` 都没做到：

1. **六段全部用英文写**，只有台词保留原文（`<d>[Chinese] ……</d>`）。我们的画面描述是中文。
2. **`detailed_description` 一般 350–500 个英文词**，按时间写清构图、人物、动作、镜头运动和声音。我们的只有一百来个字，5 秒的片子模型没东西可演，就自己切镜头。
3. **只用来定人物、场景的参考图不能单独写成 `<Picture N>` 一行**，要写进 `<Subject N>` 的定义里；单独的 `<Picture N>` 是给首帧、关键帧用的。我们写成了「`<Picture 2>` is the reference for 林晚」，模型就把它当成后面要切到的关键帧。

只改第 3 条（`refwording`）或去掉场景图（`noscene`）都不够；三条一起照官方写（`guidefmt`）才好。
