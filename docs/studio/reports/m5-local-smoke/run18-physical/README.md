# 第十八轮：插入镜头只许微动、内心独白不进 take、提示词写进物理约束（第 15o、15p 步，2026-11-10）

Kelvin 看第十七轮成片提的硬瑕疵（根因见 `../../m5-quality-defects.md`）里，有两处是我们自己引入的，先在 M5 修；道具尺寸 / 带字的道具 / 分镜层面的约束并进 M5.5。Kelvin 同时要求：**提示词里就要考虑物理世界的约束、前后一致，规避穿帮**。

## 改了什么

- **镜头类型**（15o）：镜头里没有人物、也没有人说话的是「插入镜头」（1-03 便利贴、1-07 手机）。改写时第 15j 步的「2–4 个动作排满」只用在表演镜头；插入镜头只许微动（光线、镜头慢推、至多一滴水滑下），东西本身不发生任何事：不倒水、不溅、不爆开、不掉落，湿 / 破 / 有字的状态和首帧一样。检查器在插入镜头里见到 pour / burst / splash / stream of water 这类词就带着问题重问。
- **物理世界和前后一致**（Kelvin 的要求）：改写的系统提示词加第 11 条：道具按真实尺寸对照人物、材质按现实（雨是慢慢打湿，纸变软、手写墨迹微晕）、东西不会凭空出现 / 消失 / 变色 / 跳到手里（要伸手、拿起）、状态延续（开着的门、手里的东西、光源方向）、字和首帧一样、人体自然、不穿模。表演镜头里，一个改变状态的动作只做一次，犹豫要演出来，不重复。
- 关键帧提示词每张都加「真实感」一段（同样的尺寸、材质、光源、手写、人体、不穿插）。道具参考图的类别说明从「放在干净的浅色背景上」（就是白底产品照，伞就是这么来的）改成实拍质感、有使用痕迹、带一个看得出尺寸的东西。**这两处要重画素材和关键帧才看得到，这一轮没重画**（M5.5 一起验证）。
- **内心独白 / 画外音（15p）**：剧本里 `vo` 的台词不再进 take：不送配音轨、不写进提示词的 `<d>`，提示词里注明「画外，剪辑时另铺，这条片子里没有人说话、嘴闭着」；先配音的镜头只有内心独白时，出 take 前也不用先配音。剪辑时把这句单独铺上去（M7 混音时按 OS 处理）。
