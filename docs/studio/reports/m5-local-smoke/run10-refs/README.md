## 结论（等 Kelvin 定）

- **连续镜头带场景参考图不行**：r2v 把场景图当成「要拍的地方」，尾段一结束就切过去。
- **伞的颜色错在上游**：黑伞是 1-05、1-06 的关键帧画进去的（分镜规划没把动作里提到的红伞放进这两镜的参考素材，关键帧模型自己补了一把黑伞，第八轮原因 2），1-08、1-09 都是接着它来的。i2v 老老实实接着黑伞；r2v 带了道具图就在镜头中间把它变红，看得出来。所以光改视频的规则表治不了，要靠 15f 的另一半：分镜规划把动作 / 画面里提到的道具补进参考素材，关键帧就会按红伞画。
- 可选的默认规则：
  1. **连续镜头照旧走 `h3-i2v`**（接得最稳），道具颜色靠上游关键帧；非连续的无台词镜头走不走 r2v 另说（这一轮没测，非连续镜头有锁定关键帧当首帧锚，i2v 和 r2v 的差别要另测）。
  2. 连续镜头有锁定的道具 / 角色图时走 `h3-r2v`、**不送场景图**：道具颜色会被拉回参考图，但上游画错时会在镜头中间变色。
