# 第十五轮：连续镜头的尾段怎么送、带不带参考图（第 15m 步，2026-11-09）

调研报告第 5 节的社区做法里，有三条可以直接对照测：尾段别经过有损压缩、音频上下文短一点（18 帧）、连续镜头每段都带同一组角色参考（Ref2VA）。这一轮在第十一轮数据的副本上（1-08、1-09 采纳的是加了末帧锚点的那条），每个镜头同种子各出一条：

| 方案 | 怎么送 |
|---|---|
| old | `h3-i2v`，尾段从上一镜**裁过头**的片子切，crf 10 + AAC（第 15m 步以前） |
| lossless | 同上，尾段从上一镜**原片**切，无损（`-qp 0` + ALAC）——**现在产品的做法** |
| audio18 | lossless，尾段的声音只送前 18 帧 |
| r2v | `h3-r2v`，lossless 尾段 + 林晚、红伞两张锁定图，不送场景图（第十轮：送场景图会切过去） |

```
DRAMA_LIVE=1 uv run --no-sync python scripts/smoke/cont_compare.py --home <第十一轮的数据目录>                    # 1-09，四种
DRAMA_LIVE=1 uv run --no-sync python scripts/smoke/cont_compare.py --home x --work <上面的副本> --label 1-08 --only old,lossless,audio18
```

old 和不送场景图是本进程里的补丁，其余就是产品本身。

## 结果

| | 引导段第 0 / 10 / 21 帧 和上一镜尾段比 | 切点 | 切点后 0.5 秒的响度（上一镜最后 0.5 秒） |
|---|---|---|---|
| 1-09 old | 36.4 / 36.2 / 36.5 dB | 30.9 dB | −36.0 dBFS（−40.4） |
| 1-09 lossless | 36.4 / 36.1 / 36.5 | 30.9 | −52.0 |
| 1-09 audio18 | 36.4 / 36.1 / 36.5 | 31.2 | −50.8 |
| 1-09 r2v | 35.4 / **29.0** / 35.8 | 30.9 | **−22.0** |
| 1-08 old | 37.2 / 37.0 / 37.6 | 37.0 | −50.6（1-06 结尾是静音 −95） |
| 1-08 lossless | 37.2 / 37.1 / 37.7 | 37.0 | −27.0 |
| 1-08 audio18 | 37.2 / 37.1 / 37.7 | 37.0 | −49.9 |

- **画面**：尾段无损、声音短到 18 帧，引导段和切点都在 0.1 dB 以内，没有差别。引导段贴得多紧取决于 H3 自己的 VAE（约 36–37 dB），不是我们那一次 crf 10。
- **声音**：切点后半秒的响度在几种方案之间差 20 dB 以上，但没有规律（1-09 是 old 最响，1-08 是 lossless 最响）。这是生成本身每次不同，不是尾段的编码。两三段的链上看不出 18 帧更好；社区说的「每接一次闷一点」是长链（很多段）上的现象。
- **r2v 带参考图**：更差。`sheet-r2v-1-09.jpg` 第 4 → 5 格伞直接到了她手里，没有拿起来的动作；引导段第 10 帧漂到 29 dB；切点后声音突然大 18 dB。i2v 这几条伞已经是红的（`sheet-lossless-1-09.jpg`）：15f 在上游把伞画对之后，参考图就不需要了。
- **每段换种子**：产品本来就是每条 take 各抽一个种子（第十一轮这条链 1-06 / 1-08 / 1-09 的种子各不相同），不用改。

图：`cut-1-0x.jpg`（第一格是上一镜最后一帧，后面依次是各方案第一帧）、`sheet-*-1-0x.jpg`（每秒两帧），提示词 `prompt-*.txt`，原始报告 `report-1-0x.txt`。片子（不进 git）：`../originals/run15-continuity/*.mp4`。耗时：1-09 i2v 约 197 秒、r2v 241 秒；1-08 约 304 秒。

## 定下来的（第 15m 步）

- 尾段**改成从原片切、无损编码**（`vid.py` 取 `raw`，`media/video.py:tail_clip` 默认 `lossless`）：画面上量不出差别，但少一次有损压缩、不多花什么（每段尾段约 5 MB，原来约 1 MB）。
- 尾段声音**保持 22 帧**（`TAIL_AUDIO_FRAMES`，留着可调）。
- 连续镜头**照旧走 `h3-i2v`**，不带参考图（和第 15f 步 Kelvin 定的一致）。
