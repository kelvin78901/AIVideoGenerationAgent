## 1-06（`tts`）→ 1-08（接 1-06 的尾帧）

- 1-08：`comfy/h3`，213 s，6.29 s，首帧就是 1-06 的尾帧（`params.request.first_frame` 等于 1-06 的 `last_frame`）；1-06 尾帧和 1-08 第一帧（裁掉 0.3 s 后）PSNR 35.0 dB，接得上（`tail-1-06-1-08.jpg`）。

## 1-04 同种子、同首帧：原生同步 vs 先配音再对口型（Kelvin 要的对比）

种子 191503631，首帧同一张（`0a137597ee78`）。`1-04-native-vs-tts.jpg`：上两行原生同步，下两行先配音。

| | 原生同步（`native`） | 先配音再对口型（`tts`） |
|---|---|---|
| 工作流 | `comfy/h3-r2v`：林晚音色样本 + 林晚、楼道两张参考图 | `comfy/h3`：图生视频 + 配好的台词音轨，不收参考图 |
| 耗时 | 183 s | 159 s |
| 效果 | 镜头推近，抬头说「……周屿？」，表情和口型自然 | 画面几乎不动；**H3 把台词当字幕画进画面**（好几帧出现「周屿」）；人物只靠首帧保持一致 |

结论：本地 H3 的 `tts` 路线现在明显不如原生同步。要用它，提示词得明确「不要字幕 / 画面文字」，再看口型；也可以考虑 `tts` 走 R2V（音轨 + 参考图）。片子在临时目录，没进仓库。
