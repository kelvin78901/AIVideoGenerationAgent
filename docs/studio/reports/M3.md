# M3 素材与配音 · 里程碑报告

> 分支 `m3-assets-voice`（从合并 PR #4 后的 main 3ffd6a2 切出），计划 [`docs/studio/plans/M3.md`](../plans/M3.md)。写给 Kelvin，也作为 PR 描述。

## 做了什么

M3 把「剧本 → 素材清单 → 参考图 / 画面文字 / 音色 → 锁定 → 台词配音」这一段在后端做通了：

- Mock 下整条流程都能走。
- 三家图像 API 和 MiniMax 配音已按官方文档接好，并用真钱调过。
- 本地这几样在你的 5090 上经真实安装器装好、真跑过：ComfyUI（Qwen-Image-2512 出图、Qwen-Image-Edit-2511 补视图）、Qwen3-TTS、IndexTTS-2.5、RapidOCR。
- 素材页、剧本页的配音部分接上了后端，对应的 MSW 示例数据已删掉。

**候选、锁定、媒体基础（第 1 步）**

- 候选类组件（参考图、画面文字、音色）一次运行出一个版本，4 张候选都在里面，不自动采纳。「选这个」记在产物上。
- 锁定会出一个 `pick` 版本，只含选中那张，同时采纳、锁定、写闸门记录。同一张图从哪一版锁定，哈希都一样。
- 媒体产物的哈希包含文件本身：换了图或音频，下游就变「待更新」。
- 新接口 `GET /files/{sha}` 取文件，支持 Range，音频能拖进度。
- 台词音频统一处理成 48 kHz、−18 LUFS，后端算好波形。前端新加共用组件 `AudioPlayer`。
- 迁移 `0016`。

**素材分析（第 2 步）**

- 每集一份素材清单。人物、音色、场景、提到的设定道具按规则从剧本和设定里取，模型只写描述，再补设定里没有的道具和画面文字。
- 同一个人在不同集是同一条素材。清单**只增不删**。
- 用户改的东西（描述、画面文字设置、音色来源）存在产物上，重新分析不会覆盖（迁移 `0017`）。
- 「重新分析剧本」改成任务。新接口：出场矩阵。

**参考图、补视图、上传、锁定，素材页接后端（第 3–4 步）**

- 本地出 4 张草稿，选一张后「用 API 出终版 · 约 $0.14」，以它为参考出 1 张（你定的第 5 项）。
- 能上传参考图，上传的图算一个候选。
- 角色锁定后自动补视图。
- 道具描述里提到的已锁定角色，会拿那张锁定图做参考。
- 解锁走影响范围。
- 素材页多了「清单 / 出场矩阵」切换，「出现在」改成场，点了跳到剧本那一行。

**画面文字 + OCR（第 5 步）**

- 两种做法：模型直接出字，或后期贴字（底图不要字，贴字预览在前端叠，真正的合成在 M7）。
- 每张候选过一次本地 RapidOCR，逐字比对。读到的字不一致时，锁定前先问你「仍然锁定」。

**音色（第 6 步）**

- 「重跑」= 免费试听：本地 3 个，读这个角色的台词。
- 选一个后「用 MiniMax 出终版」：做音色设计，再出 5 个情绪变体（平静、愤怒、哭腔、耳语、喊叫）。也可以全程本地（IndexTTS）。
- 只有终版能锁定，而且整版锁定。「声音克隆」灰掉，写「之后支持」。

**台词配音 + 时长（第 7 步）**

- 每句台词一个配音产物，跟着这一句的台词和说话人的锁定音色走。
- 情绪：你手动设的优先，否则按语气里的关键词。
- 素材页：「台词配音 n / m · 全部配音」，配之前先估价确认。音色详情里能逐句播放、改情绪、重配。
- 剧本页：配过音的台词能播放，显示真实时长；场标题下写「台词 x 秒 · 已配音 n / m」。
- 时长算到台词和场；镜头时长的函数写好、测好，M4 接上。

**素材闸门、影响范围、级联（第 8 步）**

- 「去做分镜」要求本集用到的素材都已锁定；没锁完时提示还差哪几条。
- 改已锁定素材的描述、画面文字或音色来源，先弹影响范围。
- 级联永远不会重画、也不会解锁候选类的素材（参考图、画面文字、音色）；补视图和配音照常跟着走。
- 你看过后定的：素材计数按本集用到的算（7 / 10）；候选卡改成定宽小卡，能放大看。

**Mock 端到端（第 9 步）**

- `tests/e2e/test_script_to_dub.py` 起真实后端进程：从导入小说一路走到每句配音，场时长 = 音频之和，13 条素材都能出候选并锁定。

**真实适配器（第 10–12 步）**

- 图像三家：Nano Banana Pro（`gemini-3-pro-image`）、GPT Image 2（`gpt-image-2`）、Seedream 5.0 flash。
- 按 token 计费的照 token 记账。
- 「测试连接」连出图模型一起查，只发不花钱的请求。
- MiniMax：配音、音色设计，用国内站，按人民币价记账。
- 本地 Python 运行时：一个模型一个常驻 worker，各自的 uv 环境，加显存租约。
- ComfyUI 适配器：提交 → 轮询 → 下载；超时或取消时只停我们自己的任务；可复现字段记在版本上。
- 安装器加 `uv_sync` 步骤；清单加 4 项（`rt_qwentts`、`rt_indextts`、`rt_ocr`、`w_img_t2i`）。

**本机真装真跑（第 13 步）和真实冒烟（第 14 步）**：见下面「本机和真实冒烟」。

**收尾（第 15 步）**：SPEC 补了 M3 的实际做法（4.1、4.2、5、6.3–6.5、7.5–7.7、9、9.1、12.1）。重截了两张截图：`assets-views` 改成 6 张视图，`assets-dub-confirm` 换成改价后的金额。

## 和计划不一样的地方

**你中途定的**（都在 DECISIONS 里）：

- **素材计数**按本集用到的算（7 / 10），不按整张清单（原型 7 / 13）。
- **候选卡**改成定宽小卡，图上有「放大」。
- **补视图**：
  - 从 3 张（侧面、背面、表情拼图）改成 6 张（侧面、背面、平静、微笑、愤怒、难过），表情一张一种；
  - 不用 4 步加速，改用官方的 40 步（新工作流 `qwen-image-edit-hq`），每张图带负面提示。草稿、画面文字仍是 4 步。
- **OCR**：只有句末标点没读到，不算漏字。
- **确认过的任务**可以多花一点余量：确认金额的 10% 和 $0.05 中取大的。
- **MiniMax 用国内站**，按人民币价记账。音色终版约 $1.40，低于单次上限，不再每次都要确认。
- **启动脚本默认真实检测**：Setup 页扫的是这台电脑，模型仍走 Mock。

**工程上的改动**（理由见 DECISIONS 各步）：

- **音色设计费 $1.39**（国内价）记在第一次用这个音色合成的那次调用上，不记在设计那一次。MiniMax 是在第一次合成时才收这笔钱。
- **GPT Image 2 的尺寸**：竖屏用 1088×1920，不是计划写的 1152×2048（那是第三方渠道的固定尺寸，官方允许任意 16 的倍数）。
- **兼容表有两行变成「原生支持」**：「带字关键帧 · GPT Image 2」和 21:9 下的「关键帧 · Nano Banana Pro」。原型是按第三方渠道的限制画的。
- **画面文字的提示词改成「一张画面、只有这一处字」**。原来写「4 张候选」，本地模型照字面画成了拼图。
- **台词结尾留 0.3 s 缓冲**（你听出尾音被切）；Qwen3-TTS 按字数限长（有一次 9 个字说了 78 s）。
- **GPU 队列**先跑完已加载模型的任务，不再每个任务都换一次模型（硬规则 8）。
- **出场矩阵的列**：除了角色和场景，道具、画面文字、音色也列出来了。
- **界面多出的行**（原型里没有）：
  - 「模型与兜底」页多「补视图」「台词配音」「文字核对（OCR）」三行；
  - Setup 页多 4 行（三个运行环境、一组权重）。
- **拆分**：第 7、8 步各拆成后端、前端两次提交，第 12 步拆成上、下两次。

**按计划不在 M3 做**：

## 遗留问题

- **估价和实际有出入**：
  - Nano Banana Pro 估价偏低约 2.7%（没算输入和思考 token），现在由确认余量兜住；
  - GPT Image 2 按 token 估，偏高约 30%。往高估，没改。
- **还没换价、没核对的模型**：H3 视频和 `minimax/m3`（写作模型）还是国际价，比国内价高约 13%，M4 用到时一起换。
- **图和声音的效果**：
  - Qwen-Image 偶尔在角落加一小块像水印的模糊字（「难过」那张），之后看要不要在负面提示里压；
  - 真实音色和配音「有的能用、有的不能用」，现在靠多出几个候选来挑。
- **本地模型的已知问题**：
  - ComfyUI 偶发 `hostbuf_file_reader_read failed`（换模型、内存紧时）。我们按 `comfy_failed` 兜底，重跑就好；
  - 运行环境的锁文件写的是 wheel 的完整地址，PyPI 镜像对它不起作用。国内装得慢的话，以后另出一份指向镜像的锁文件。
- **留到 M4 / M5 的**：
  - `model_call` 还没有 `workflow_id` 等三个可复现字段（版本上已经有），M5 接工作流库时加；
  - 示例剧集的镜头仍由 MSW 叠加在素材页和进度上，M4 删。
- **没做的接口**：手动新建素材（`POST /series/{id}/assets`）。
- **可选、没排期**：画表情前，把锁定图的头肩裁出来当参考，脸会更大。
