## 通用的问题

约束现在只是提示词里的一段自然语言：道具多大、上面写了什么、是不是湿的、这个镜头该动多少、这句台词是嘴说还是心里想，都没有结构化的字段；出了关键帧、出了 take，也没有任何一步按这些约束去检查。于是每一环（素材、分镜、关键帧、改写、H3）都可以自己「补」，补错了没人发现。第 15j 步为了治定格加的「动作排满」规则，在静物特写上就补出了倒水。

## 方案：镜头契约 + 每一环按契约检查

**1. 镜头契约（分镜阶段生成，结构化，跟着镜头走）**

- **镜头类型和动作预算**：表演 / 动作 / 对白 / 插入（静物、空镜）。插入镜头只允许微动（光线、一滴水、镜头极轻的漂移），不许新增事件；表演镜头 1–2 个动作；动作镜头按片长。第 15j 步的「2–4 个动作」只用在动作镜头。
- **起止状态**：这个镜头开始时、结束时人和道具是什么样（门开着 / 关着、伞在哪只手里）。连续镜头的下一镜从这里接；同一个状态变化（开门）一个镜头里只能发生一次，**不许撤销再重做**（开 → 关 → 开）。犹豫要演出来（手搭门把、停住、吸气），不是重复动作。
- **道具和它的状态**：道具在这个镜头里的状态（便利贴：有字、边角湿、墨迹微晕）。**状态是摆出来的，不是演出来的**：除非这个镜头的动作就是这个变化，提示词里不写变化过程。
- **台词的说法**：对白（嘴要动、对口型）/ 画外（人不在画面里）/ 内心独白（OS，嘴闭着）。

**2. 道具素材带尺寸、实拍质感、带上自己的字**

- 设定里的道具加**真实尺寸和材质、新旧**（长柄伞约 90 cm、伞面尼龙、木柄磨旧）。关键帧提示词按尺寸写相对人物的比例（「伞柄到她的胯部」）。
- 道具的锁定图不再是白底产品照：要**实拍、用过、在环境里**，另加一张和人物同框的比例参考。
- **有字的道具，字是道具的一部分**：便利贴的素材图就是写了字的那张（手写、圆珠笔 / 马克笔、歪扭），不再拆成空白纸 + 文字素材。分镜引用道具就带上字；关键帧 OCR 检查（已有）对所有出现这个道具正面的关键帧都跑，空白的不让锁。

**3. 台词类型贯彻到声音和剪辑**

- **内心独白和画外音不进视频生成**：这类镜头的 take 只出画面和环境声（嘴闭着），台词作为单独一轨在剪辑里铺，按 OS 处理（贴耳、干一点、环境声压低），字幕用斜体或不同样式。这是 M7 混音的一部分，但契约字段和视频那一侧现在就能做。
- 对白才走口型：原生同步或先配音挂引导，M6 质检量口型。

**4. 检查：每一环按契约检查，不合格不进下一环**

- **分镜检查**（规则 + LLM）：同一状态变化在一个镜头里出现两次、动作预算超了、连续两个镜头机位景别一样（会像回放）、内心独白的镜头写了张嘴。
- **关键帧检查**（VLM，Gemini Flash-Lite 已经接好）：道具比例对不对、有字的道具字在不在、是不是手写。
- **take 检查**（VLM 看抽帧 + 已有的定格 / 切点 / 台词位置）：重复动作、凭空的物理事件（倒水、爆开）、字被改了、内心独白时嘴在动。这是 M6 质检的一部分，提前做和镜头契约相关的这几项。

## 放在哪里、多大

- 涉及：分镜规划（契约字段、检查）、设定（道具尺寸材质）、素材（道具图生成方式、带字的道具）、关键帧（比例、OCR 范围、VLM 检查）、视频改写（按镜头类型的动作预算，改第 15j 步的规则）、take 检查、内心独白的视频侧。混音和字幕样式在 M7。
