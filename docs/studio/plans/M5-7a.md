# M5 第 7a 步：厂商站点（国内 / 国际）和模型列表（Kelvin 2026-10-26 批准）

## 背景

Kelvin 的 Kimi 密钥是国内站的，配置写死了国际站 `api.moonshot.ai`，测试连接 401；国内站 `api.moonshot.cn` 返回 200，列表里有 `kimi-k2.6 / k2.7-code(-highspeed) / k3 / k3.1-pro(-highspeed)`。界面没地方换地址，`ProviderAccount.base_url_override` 只有「测试连接」读，实际调用不看。

Kelvin 2026-10-26 定：
1. 每个厂商能切国内站 / 国际站，**默认国内站**；
2. **模型不写死**：可选模型来自厂商返回的模型列表，用户自己选；配置里只留一张「参考价格表」，表里没有的模型标「价格未知」、用户可以填单价，不填的每次花钱前都要确认；
3. 写作 LLM 全部按列表选；媒体模型厂商能列的也列（OpenAI、Gemini），列不了的（MiniMax 视频 / 配音、火山方舟）保留配置里的 ID，但界面上能改；
4. Kimi 默认用 **K3.1 Pro**；
5. 放进 M5，在第 8 步（生成页接口）之前做，同一个分支、同一个 PR。

顺带补一个硬规则 6 的漏洞（梳理时发现）：现在价格未知的模型按 $0 估价，**从不**进 `waiting_confirm`。

## 设计

### 1. 配置：`providers.yaml` 的厂商行加 `sites`，`models` 变成参考表

```yaml
- id: moonshot
  name: Moonshot（Kimi）
  default_site: cn
  sites:
    cn:   { base_url: https://api.moonshot.cn/v1, key_name: MOONSHOT_API_KEY, docs: … }
    intl: { base_url: https://api.moonshot.ai/v1, key_name: MOONSHOT_INTL_API_KEY, docs: … }
  model_defaults: { json_mode: true, request: { thinking: { type: disabled } } }   # 列表里来的模型默认这样调
  models:            # 参考表：已知模型的显示名、单价（按站点）、上下文、请求字段；不再决定「能选什么」
    - { key: moonshot/kimi-k3.1-pro, model_id: kimi-k3.1-pro, display: Kimi K3.1 Pro, price: { cn: {…CNY}, intl: {…USD} }, max_context: … }
    - { key: moonshot/kimi-k2.6, … }   # 留着：历史版本、示例数据在用
```

- 有两站的：moonshot、dashscope、zhipu、minimax_llm（MiniMax 的配音 / 视频价已经是国内价，国际价从官方页补）。只有一个地址的（deepseek、volcengine、google、openai、openrouter、local_llm）照旧写 `base_url` / `key_name`，加载时当成只有一个站点。
- **密钥按站点分开存**：国内用现在的名字（`MOONSHOT_API_KEY`、`MINIMAX_API_KEY`，你现有的两个密钥正好都是国内的，不用重填），国际站加 `_INTL`。
- 参考表里的价格按站点写（国内人民币、国际美元），本步实现时**逐个对官方价格页核对**（Kimi K3.1 Pro 国内价这次一定核）。
- `core/config.py`：`LlmProvider` 加 `sites`、`default_site`、`model_defaults`；`TokenPrice` 允许按站点；旧写法（单个 `base_url`）继续能读。`docs/studio/seed/providers.yaml` 同步。

### 2. 数据库：迁移 `0021`

- `provider_account` 加 `site`（空 = `default_site`）、`models_json`（最近一次拉到的列表：id、拉取时间）、`enabled_json`（用户勾选启用的模型 id）。`base_url_override` 继续保留（高级用法，比如代理），优先级最高。
- 新表 `model_setting`：`model_key`、`model_id`（覆盖配置里的 ID，媒体模型在界面上改的）、`price_json`（用户手填的单价，同 `Pricing` 的字段）、`updated_at`。（`config_override` 管的是路由，不放这里。）

### 3. 后端：注册表从「配置 + 数据库」生成

- `modelhub/registry.py`：`specs_from_config(cfg, accounts, settings)`——每个厂商取当前站点的 `base_url` / `key_name`；LLM 的模型 = **启用的模型 id**（列表里勾了的），参考表里有的用表里的 key 和参数，没有的 key 是 `<厂商>/<model_id>`、参数用 `model_defaults`、价格查 `model_setting`，再没有就是未知价；媒体模型照配置，`model_id` 可被 `model_setting` 覆盖、`base_url` / `key_name` 跟账号当前站点走。
- `Registry.reload_provider(provider_id)`：换站点、勾选模型、填价格之后重建这个厂商的 spec（复用 `add_spec`，删掉不再启用的）。启动时（`api/state.py`）先读库再建注册表。
- **默认启用**：拉到列表时，列表里出现在参考表中的模型自动勾上，其它不勾；从没拉过列表的厂商沿用参考表（这样没填密钥的机器、测试、示例数据行为不变）。
- **路由里用到的模型消失了**（没启用 / 换了站点后列表里没有）：目录里不显示；路由解析到它时按现在的 `unknown_model` 报错，界面上「模型与兜底」那行标红提示去换（不悄悄换模型）。
- `components.yaml`：写作组件的 `api:` 不再列 15 个 key，改成 `api: [llm]`（「所有启用的写作模型」），`balanced.api` / `fallback_to` / `cheap_api` 这些默认值保留具体 key；`moonshot/kimi-k2.6` 在默认值里换成 `moonshot/kimi-k3.1-pro`。`llm_ui_order` 改成厂商的顺序（选择器按厂商分组，前 6 个直接显示的规则不变）。

### 4. 后端接口（`api/routes/providers.py`）

- `GET /providers`：每个厂商加 `sites`（各站点地址、有没有密钥）、`site`、`models`（列表：id、是否启用、参考表 / 手填价格、未知价标记）、`models_fetched_at`。
- `PATCH /providers/{id} {site}`：换站点 → 重建 spec。
- `POST /providers/{id}/key {api_key, site?}`、`DELETE …/key?site=`：按站点存。
- `POST /providers/{id}/test`：用当前站点，拉到的列表**存进库**（现在只返回不存），返回启用情况。
- `PUT /providers/{id}/models {enabled: [...]}`：勾选。
- `PUT /models/{key}/setting {model_id?, price?}`、`DELETE …`：手填单价、改媒体模型 ID。
- 媒体：OpenAI、Gemini 测试连接时顺带拉列表（`GET /models`），给媒体模型改 ID 时当下拉建议；MiniMax、火山方舟没有列表接口，只能手填。

### 5. 硬规则 6：未知价先确认

- `EstimateOut` 加 `priced`；`Budget.before_enqueue(…, priced=False)` → `Verdict(False, reason="unpriced")`，任务进 `waiting_confirm`；确认弹窗文案「这个模型没有单价，花多少不知道」。手填了单价就按单价走正常的上限检查。
- 路由的 `BudgetGuardImpl` 对没有任务的单次调用同样处理（`confirmed_usd` 为空且未知价 → `NeedsConfirm`）。
- 记账：未知价的调用 `cost_usd` 记 0、`model_call` 加标记 `unpriced`（表头花费旁边提示「有 n 次调用价格未知」——只出后端字段，界面在第 9 步表头做）。

### 6. 前端

- **服务页的密钥对话框**（`pages/models/KeyDialog.tsx`）：顶部「国内站 / 国际站」切换（只有一个站点的不显示），每个站点自己的密钥状态；测试连接后显示**模型列表**：勾选启用、显示参考价 / 手填价 / 「价格未知 · 填价格」（小表单：输入 / 输出每百万 token，币种）。
- **模型选择器**（`components/ModelPicker.tsx`）：数据仍来自 `/config/components`，按厂商分组；未知价显示「价格未知」徽标；路由用到了没启用的模型时那一行标红。
- 媒体模型行：能改 `model_id`（有列表的给下拉）。
- i18n 两种语言同加；`test/backend.ts`、`test/fakes/config.ts` 跟着改；`config.json` 快照重导；`mocks/fixtures/demo/models.ts` 里写死的模型列表删掉、改读真实接口（这块 MSW 本来就不拦 `/providers`）。
